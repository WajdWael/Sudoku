# Sudoku + POWR

- `index.html` – full game with SDK integration
- `powr-sdk.js` – patched SDK (exposes window.POWR)
- `.nojekyll` – disables Jekyll on GitHub Pages

### Deploy to GitHub Pages
1. Push these files to a new repository.
2. In Settings → Pages, set source to "main" branch, "/ (root)".
3. Wait 2 min and open your site.

### Test with POWR
When opened via the platform (with ?token), the status will show connected and scores will submit.
